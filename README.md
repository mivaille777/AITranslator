# AITranslator

AITranslator 是一款面向 Windows 的桌面划词翻译工具，帮助你在阅读网页、文档和其他应用内容时快速查看中文译文。

## 功能

- 自动检测选中文本并翻译，自动划词翻译默认开启。
- 支持使用 `Alt+Q` 快捷键手动触发翻译。
- 支持 Word、Chrome、Edge、记事本等常见 Windows 应用。
- 通过悬浮窗展示译文，支持拖动、置顶、隐藏和恢复显示。
- 支持复制译文、复制原文、显示/隐藏原文和切换预设语言。
- 支持紧凑卡片、多行内容展开、深色界面和透明度等显示设置。
- 支持托盘运行、设置管理和翻译结果缓存。
- 使用 Google Translate 网页翻译服务，无需配置 Google Cloud 凭据。
